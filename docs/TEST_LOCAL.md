# 배포 전 직접 테스트 (이 PC에서)

## 열기
| 화면 | 주소 | 비고 |
|---|---|---|
| 사용자 | http://127.0.0.1:8000/?k=dev | 로컬 입장 키 `dev`. 한 번 들어오면 키 없는 주소로도 열림 |
| 관리자 | http://127.0.0.1:8000/admin | 로컬 암호: 전체 권한 `dev-full` / 읽기 전용 `dev-read` |

- 크롬·엣지에서 **F12 → 기기 모드(Ctrl+Shift+M)** 로 휴대폰 크기(예: iPhone 14)로 보면 실제 화면과 비슷함
- **처음 리더로 다시 해 보기**: 사용자 화면에서 F12 → Application → Local storage → `http://127.0.0.1:8000` 항목 지우기(또는 시크릿 창). 시크릿 창마다 새 리더로 취급됨
- 서버가 꺼져 있으면 PowerShell 에서(폴더: `leader-reflection-handoff`):
  `.venv\Scripts\uvicorn main:app --port 8000`

## 시나리오
### A. 처음부터 끝까지 (리더 1명)
- [ ] 키 없이 http://127.0.0.1:8000/ (시크릿 창) → '안내 메일이나 메신저의 링크로 들어와 주세요'만 보임
- [ ] `?k=dev` 로 열기 → 안내 → 리더명: 보기 순서가 창마다 달라짐, 아무것도 안 고르면 화살표 흐림
- [ ] '직접 적을게요'에 `사번 123456` → 막힘 안내 / `묻고 듣는` → '묻고 듣는 리더님으로 불러 드려요'
- [ ] 핵심 메시지 1~5 → 키워드(4개째는 안 눌림, '잘 떠오르지 않아요'는 단독). 시크릿 창 두 개에서 키워드 순서가 서로 다른지('잘 떠오르지 않아요'는 늘 맨 뒤), 같은 창에서 뒤로 갔다 오면 순서가 그대로인지
- [ ] 리더명 '직접 적을게요'에 `홍길동` → '사람 이름처럼 보여요…' 안내(다음으로는 넘어갈 수 있음), `묻고 듣는` → 안내 없음
- [ ] 구성원 떠올리기 → 별명·상황 → 체크 1~5(다 답해야 '다음') → 결과 정리 카운트다운 → 결과 1~3 → 실천 → 완료(꽃가루)
- [ ] 결과 문구가 기대와 맞는지(예: 케어 문항만 '했어요' → '말하지 않는 리더')
- [ ] 실천 '직접 쓸게요'에 별명을 넣어 쓰기 → 완료 화면엔 그대로, 관리자 '문항 분석 → 직접 쓴 문장'에는 ○○로
- [ ] 결과 2는 '했어요'가 3개 이상이면 3개, 결과 3은 언제나 3개(못 했어요 → 체크 5에서 고른 순간 → '이번에 해낸 행동 · 다음에도 이어 가기')
- [ ] 모든 행동 '했어요' + 체크 5 모두 '아니요' + 상황 '없음' → 결과 3은 이어 가기 3개, 실천 첫 보기 '결과에서 추천한 말'이 공통 문장
- [ ] 실천 '직접 쓸게요' 아래 안내가 '구성원 실명은 적지 말아 주세요…'인지
- [ ] 상황 7개를 모두 고르면 실천 보기가 '결과에서 추천한 말' + '다음에 해 볼 것 · …' 2개(모두 '했어요'면 '지난 면담 이후를 물어볼 때' 1개)
- [ ] 케어 행동 4개 모두 '했어요' + 체크 5에서 '말이 세게'·'결과 전하는 데 급했던' 둘 다 → 결과 1에 '개인적 케어 행동은 4/4개 했지만…' 한 줄(PDF 에도)
- [ ] 개발자 도구(F12) → 기기 모드에서 User-Agent 를 KakaoTalk 등으로 바꿔 새 시크릿 창으로 열기 → 안내 화면에 '메신저·메일 앱 안에서 열었어요…', 완료 화면에 '캡처해 두세요'
- [ ] 완료 → 'PDF 다운받기' → PDF 내용 확인 / '동료에게 추천하기' → '리플렉션 링크가 복사되었어요.' → 복사된 링크를 새 시크릿 창에 붙여 넣으면 안내 화면
- [ ] 관리자 '사용 흐름' → '완료 화면 버튼 클릭'에 누른 횟수가 늘었는지

### B. 이어 하기·뒤로 가기
- [ ] 체크 3쯤에서 창 닫기 → 다시 열면 체크 3 + '[리더명]님의 기록으로 이어서 해요'
- [ ] 그 안내의 '다른 리더예요' → 확인 → 안내 화면부터 새로 시작(같은 브라우저에서 다른 리더명으로 시작 가능). 관리자에는 앞 리더 기록이 그대로
- [ ] '처음부터 다시' → 그 구성원 점검만 지워지고 구성원 떠올리기로
- [ ] 결과 1에서 뒤로 → 결과 정리를 건너뛰고 체크 5, 답을 바꾸고 '결과 보기' → 결과가 다시 계산됨
- [ ] 완료 후 '다른 구성원 점검하기' → 별명·상황이 비어 있음
- [ ] STEP 1을 끝낸 뒤에는 리더명을 바꿀 수 없음

### C. 관리자
- [ ] `dev-read` 로그인 → 설정 탭·CSV 버튼 없음
- [ ] `dev-full` 로그인 → 네 탭 숫자가 A·B에서 한 것과 맞는지, '표로 보기', 막대에 마우스 올리기
      (가짜 데이터가 있으면: A를 시작하기 **전에** 대시보드 숫자를 적어 두고 늘어난 만큼만 비교. 참여자 탭은 내 리더명으로 검색)
- [ ] 참여자 탭: 내가 만든 리더명 + 4자리 번호, 점검별 경향 칩. 체크 응답·문장은 안 보이는지
- [ ] 설정: 마감일을 어제로 → 사용자 화면이 '이번 차수는 마감됐어요'만 → 다시 비우기
- [ ] 설정: 입장 키 바꾸기 → 예전 `?k=dev` 링크가 막힘(테스트 뒤 다시 `dev` 로 바꾸거나 설정에서 지우기는 안 되므로 새 키 사용)
- [ ] 설정: 참여자 삭제(리더명 + 번호) / CSV 4종 내려받아 엑셀에서 한글 확인
- [ ] 설정: '판정 기준값 미리보기'에 0.25·0.5(지금 값)·0.75·1.0 분포가 나오고, 한 칸 70% 이상이면 '쏠림'
- [ ] 설정: 대상 인원을 지금 등록 수보다 작게 → 대시보드 1.1 에 빨간 경고 줄 → 다시 170
- [ ] 같은 리더명을 '직접 적을게요'로 두 브라우저에서 만들기 → 참여자 탭에 '같은 이름 2명'
- [ ] 문항 분석 2.8: 문장 옆 '삭제' → 확인 → 목록에서 사라지고 2.6 '직접 썼어요' 비율은 그대로. `dev-read` 에서는 '삭제'가 없음
- [ ] 로그인 5번 틀리기 → 10분 잠김

### D. 접근성·기타
- [ ] Windows 설정 → 접근성 → 시각 효과 → 애니메이션 효과 끄기 → 화살표·엄지척·꽃가루가 멈춤
- [ ] 키보드(Tab·Enter)만으로 끝까지 진행 가능
