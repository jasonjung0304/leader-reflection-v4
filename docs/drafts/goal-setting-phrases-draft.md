# 실천 문장 초안 — 1월 목표설정 면담용 (2026-11-27 작성·같은 날 적용)

> **적용됨(2026-11-27)**: 아래 제안을 `content/content.json` 에 그대로 반영했다. 다만 `action.title` 은 휴대폰 폭(375px)에서 "면담은"만 한 줄에 남아 줄바꿈만 "[별명]님과의 / 1월 목표설정 면담은 / 이렇게 시작해보세요."(3줄)로 바꿨다. 결과 3 조언(advice) 고쳐 쓰기는 이 초안에 넣지 않았다(따로 결정).

리플렉션이 돌아보는 면담은 **GC Review(평가 피드백) 면담**이고, 리더가 실천 화면에서 고르는 "꼭 해야 하는 말"을 실제로 쓰는 다음 면담은 **1월 목표설정 면담**이다.
지금 문장은 평가 면담을 다시 하는 말투가 많아 1월 면담과 맞지 않는 곳이 있다. 아래는 검토용으로 만든 초안이다(2026-11-27 적용).

## 왜 고쳐야 하나 — 지금 문장의 문제 4가지

1. **때 표현이 1월에 틀린다**: '올해'(지난해를 가리킴), '내년'(올해를 가리킴)이 12월 기준이다. 1월 면담에서는 '작년'·'올해'가 맞다
   (예: c1_3 "올해 스스로 가장 잘했다고 보는 일", c3_4·senior·star "내년엔…", c4_3 "올해 초에 맡았던 일")
2. **평가 면담을 다시 하는 말**: "결과와 근거를 먼저 말하고"(c1_2), "결과 이야기 전에"(c1_3), "이번 결과를 보면서"(c2_2), "목표별로 다시 짚어"(c4_1·s2), "1년 전체를 같이 돌아보고"(c4_3) — 목표설정 면담의 목적(올해 목표·기준 합의)으로 이어지지 않는다
3. **돌아보기만 하고 목표로 넘어가지 않는 말**: 울음·반발·낮은 등급·세게 나간 말 등 마음을 먼저 묻는 문장은 그대로 좋지만, 끝이 '그다음 올해 목표를 같이 정해 봐요'로 이어지지 않는다
4. **화면 제목이 '다음 면담'**: 리더가 어떤 면담을 떠올려야 하는지 분명하지 않다
