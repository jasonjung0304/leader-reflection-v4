## 사용자 화면 파일과 흐름 순서

| 순서 | 파일 | 화면 |
|---|---|---|
| 1 | Notice | 안내 |
| 2 | LeaderName | 리더명 정하기 (신규) |
| 3 | Intro | 퀵 리뷰 시작 |
| 4~8 | Review, Candor, Review2, Review3, Review4 | 핵심 메시지 1~5 |
| 9 | Keyword | 키워드 |
| 10 | Main | 구성원 떠올리기 |
| 11~15 | Checklist, Checklist2~5 | 체크 1~5 |
| 16 | Analyzing | 결과 정리 |
| 17 | Result3 | 결과 1 경향과 기억 |
| 18 | Result | 결과 2 잘한 점 |
| 19 | Result2 | 결과 3 다음에 해 볼 것 |
| 20 | Action | 실천 1개 |
| 21 | Done | 완료 |

파일 이름과 결과 번호가 다르다(Result3 = 결과 1). 흐름은 위 표를 따른다.
화면의 `[n]`, `[별명]`, `[리더명]`, `[nnnn]` 등은 자리 표시이고, 예시 문장은 '결과에 반발했어요 + 말하지 않는 리더' 시나리오다.
LeaderName은 선택된 모습을 보여 주려고 첫 보기를 미리 고른 상태다. 실제 앱은 아무것도 고르지 않은 상태로 연다.
관리자 화면의 회색 막대·빈 그래프·빈 칸은 값이 들어갈 자리다.
